# Lumina Drive v1.0.0

## Included

- Responsive layouts that wrap long localized labels and let information rows grow instead of overlapping.
- Russian, English, and Ukrainian interface languages.
- PC-to-USB and USB-to-PC file copying with progress, cancellation, and filename collision protection.
- A guarded USB erase/rebuild action with disk identity confirmation and a clear quick-format warning.
- A self-contained single-file Windows x64 executable.

## Important

The erase/rebuild action removes partitions and quick-formats the selected USB drive. It is not a secure erase and cannot guarantee that previous data is unrecoverable.
